# political-thinking-skill（政治思维技能）

[English](./README.md) · [中文](./README.zh-CN.md)

一个开源 Agent Skill，给你的 AI 助手装上一副**政治思维眼镜**：用四维度框架分析一切涉及**权力、资源、规则和人的问题**——职场政治、商业战场、体制内抉择。戴上它，看到的世界不再是好人坏人对错之分，而是**谁在什么位置，掌握了什么资源，想得到什么，能承受什么代价**。

## 为什么做这个

能力相当的两个人，一个升得快、一个原地踏步；一个合理的方案推行阻力重重，一个平庸的方案却一路绿灯——背后那只「看不见的手」有它的运动规律。这个技能把规律变成可复用的分析工作流：

- **维度一 · 利益相关方**：任何决策背后都有赢家和输家。画利益分布图——谁得利、谁受损、谁全力支持、谁暗中抵制、谁在观望。
- **维度二 · 权力真实流向**：组织架构图只是表面。实际权力流向掌握预算编制权、信息汇总权、不可替代能力的人。
- **维度三 · 规则双重性**：规则既是秩序也是武器——可用来保护自己、约束对手、创造空间、争取公平。
- **维度四 · 时间变量**：把时间轴拉长。有的博弈是速决战，有的是持久战；今天的忍让可能是明天的势能——「宁可十年不将军，不可一日不拱卒」。

## 你将得到什么

五阶段分析工作流 + 固定输出契约：

| 阶段 | 做什么 |
| --- | --- |
| 0 澄清 | 提取场景、待决问题、相关人物、现行规则、时间背景；缺信息先问不猜 |
| 1 四维度扫描 | 利益分布表、权力流向图、规则用法盘点、时间轴初判 |
| 2 多视角换位 | 代入各方真实利益写动机（不许写成立场声明/稻草人） |
| 3 时间轴推演 | 2-3 个选项 × 三档时间（3 个月 / 1 年 / 3-5 年） |
| 4 判断建议 | 结构化报告：一句话结论、利益分布、权力流向、规则博弈、时间推演、行动建议、底线与代价 |

内置护栏：只分析不操弄，拒绝贴好坏标签，承认灰色地带，每个建议都显式列出不应越过的底线与最坏代价。

## 安装

**方式 A — npx 安装器（推荐）**

```bash
npx political-thinking-skill
```

安装器会自动探测你的 agent 技能目录（如 `~/.qoder/skills`、`~/.claude/skills`、`~/.codex/skills`）并复制技能文件。常用参数：

```bash
npx political-thinking-skill --list           # 查看已知的技能目录
npx political-thinking-skill --target <dir>   # 安装到自定义目录
npx political-thinking-skill --uninstall      # 卸载
```

**方式 B — git clone**

```bash
git clone https://github.com/niceforbear/political-thinking-skill.git <你的agent技能目录>/political-thinking
```

技能为纯 Markdown，无需任何运行时或依赖。任何支持 `SKILL.md` 的 agent 都可以直接加载。

## 使用

对你的 agent 说：

> 用政治思维帮我分析一下：我们部门的新方案推行阻力很大，该怎么办？

或：

> 用政治思维分析：我和平级同事竞争晋升，他更受副总器重，我该怎么选择？

agent 会走五阶段工作流：关键信息缺失时先向你提问，最后输出结构化分析报告（利益分布表、权力流向、规则博弈、时间推演、行动建议、底线与代价）。

## 训练模式

说一句「帮我锻炼政治思维」，技能会切换到日常练习模式，给你四条日常训练：开会多问谁受益、分析拉长时间轴、结论前换位三方、承认灰色地带。

## 免责声明

本技能是帮助清醒判断的分析框架，不是权术操弄手册。它刻意拒绝产出用于伤害他人的手段——让你看清规则下的暗流，同时守住自己的底线。
